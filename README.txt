To publish on GitHub Pages, unzip this package and put its contents at the
root of a GitHub repository, keeping index.html and .nojekyll at that level.
In Settings > Pages, select Deploy from a branch, choose the branch containing
these files, and select /(root). The site uses relative local assets and links
and works with a project path such as https://ACCOUNT.github.io/REPOSITORY/.

To preview locally, open index.html from the extracted folder, or serve this
folder with any static HTTP server. No build step, server code, API key, or
database is required. The embedded Google map and external links need Internet
access. The built-in Whereabouts map uses local data.
